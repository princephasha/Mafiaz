AI Workplace Productivity Assistant 
Core Features Included
Dashboard Overview: A landing view showing recent activity, quick-launch shortcuts, and a prominent "Responsible AI Disclaimer".
Smart Email Generator: Inputs for recipient context, key points, and tone selection (Formal, Friendly, Persuasive, Apologetic) with a one-click copy button.
Meeting Notes Summarizer: Structural extraction of Executive Summaries, Key Decisions, and interactive Action Item Checklists from transcripts.
AI Task Planner & Scheduler: Dynamically prioritizes chaotic workflows into a structured Eisenhower Matrix with editable checkboxes.
AI Chatbot Interface: A context-aware chat UI equipped with quick-prompt action chips.
